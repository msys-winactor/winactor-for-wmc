# ライセンス認証ツール

MSYS WinActor Adapters ライセンス認証ツールは、WinActor 連携ライブラリを利用するために必要なライセンスの登録・管理を行うデスクトップアプリケーションです。

!!! warning "重要"
    ライセンス認証が完了していないと WinActor for WMC ライブラリを使用することが出来ません。

## 主な機能

| 機能 | 説明 |
|------|------|
| ライセンス追加 | `.json` 形式のライセンスファイルをドラッグ＆ドロップまたはファイル選択で登録 |
| ライセンス一覧 | 登録済みライセンスのプロダクト名・種別・有効期限を一覧表示 |
| ライセンス削除 | 不要になったライセンスを削除 |
| ライセンス上書き | 既存ライセンスを新しいライセンスで更新 |

## ライセンス種別

| 種別 | 説明 |
|------|------|
| ノードロック (NL) | 特定の PC に紐づくライセンスです。MAC アドレスとホスト名で端末を識別します |
| フローティング (FL) | 端末に紐づかないライセンスです。有効期限のみで管理されます |

## ライセンス登録手順

1. ライセンス認証ツールを起動します
2. 「ライセンス追加」ボタンをクリックします
3. 配布された `.json` ライセンスファイルをドラッグ＆ドロップするか、ファイル選択で指定します
4. ライセンス情報（プロダクト名・種別・有効期限）を確認し、登録を確定します

!!! note "ノードロックライセンスの場合"
    登録時に PC のハードウェア情報（MAC アドレス・ホスト名）が自動的に検証されます。ライセンスに紐づけられた端末と異なる場合、登録できません。

## ライセンスファイルの保存先

ライセンス情報は以下のパスに保存されます。

```
C:\Users\Public\msys-winactor-adapters\licenses\licenses.json
```

## 有効期限について

- 有効期限が切れたライセンスには **90 日間の猶予期間** があります。猶予期間中は警告が表示されますが、ライブラリは引き続き使用可能です
- 猶予期間を過ぎるとライブラリが使用できなくなります。新しいライセンスを登録してください
