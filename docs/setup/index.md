# 準備

## ライセンス認証

MSYS WinActor Adapters ライセンス認証ツールにてライセンス認証を行います。

!!! warning "重要"
    ライセンス認証が完了していないと WinActor for WMC ライブラリを使用することが出来ません。

詳細につきましては、MSYS WinActor Adapters ライセンス認証ツール内の【マニュアル】をご参照ください。

## WinActor での設定

`[MSYS_WMC連携]` – `[01_認証関連]` – `[WMC連携(アクセストークン取得)]` ライブラリをシナリオに追加します。

プロパティ画面で WMC の URL とログイン情報を設定します。

ライブラリを実行することでアクセストークンを取得することができます。任意の変数を指定してください。

| 設定項目 | 説明 |
|----------|------|
| WMC URL | `https://manager-s.winactor.biz/********(英数字混在)` |
| パスワード | マスクにチェックを入れる等セキュリティ面の考慮を実施推奨いたします |

各 WMC 連携ライブラリを使用する際は、`[WMC URL]` と `[WMC連携(アクセストークン取得)]` ライブラリで取得したアクセストークンを指定してください。

!!! note "注意"
    WMC 連携 MSYS ライブラリを利用する際は、必ず処理の前に１つ `[WMC連携(アクセストークン取得)]` ライブラリをシナリオフローに追加してください。
