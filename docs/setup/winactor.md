# WinActor の設定

WMC と連携するための初期設定を行います。

## ライブラリの追加

WinActor for WMC ライブラリを WinActor に追加します。

### WinActor Ver7.6 以降

1. 「ライブラリ」パレットを開き、フォルダアイコンをクリックします
2. WinActor WMC 連携 MSYS ライブラリ（WinActor WMC 連携 MSYS ライブラリ一式_v{バージョン番号}.zip）を解凍し、解凍後の「MSYS_WMC 連携_v{バージョン番号}」を格納します
3. 更新アイコンをクリックします

## WMC 連携の設定

`[MSYS_WMC連携]` – `[01_認証関連]` – `[WMC連携(アクセストークン取得)]` ライブラリをシナリオに追加します。

プロパティ画面で WMC の URL とログイン情報を設定します。

ライブラリを実行することでアクセストークンを取得することができます。任意の変数を指定してください。

| 設定項目 | 説明 |
|----------|------|
| WMC URL | 例）`https://manager-s.winactor.biz/********(英数字混在)` |
| ユーザ名 | WMC のユーザ名を指定します |
| パスワード | WMC のパスワードを指定します。マスクにチェックを入れる等セキュリティ面の考慮を実施推奨いたします |

各 WMC 連携ライブラリを使用する際は、`[WMC URL]` と `[WMC連携(アクセストークン取得)]` ライブラリで取得したアクセストークンを指定してください。

!!! note "注意"
    WMC 連携 MSYS ライブラリを利用する際は、必ず処理の前に１つ `[WMC連携(アクセストークン取得)]` ライブラリをシナリオフローに追加してください。各ライブラリは WMC API との通信にアクセストークンを必要とするため、事前に取得しておく必要があります。
