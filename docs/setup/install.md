# WinActor for WMC のインストール

WinActor for WMC のセットアップを実行し、ライブラリと関連ファイルをインストールします。

## インストール手順

1. 提供された `winactor-for-wmc-setup-v{バージョン番号}.exe` を実行します

2. セットアップウィザードの指示に従い、インストールを完了します
