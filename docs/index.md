# WinActor for WMC

WinActor for WMC は、RPA ツール「WinActor」から WinActor Manager on Cloud (WMC) の各種操作を行うためのライブラリです。

## 主な機能

- **認証**: アクセストークンの取得・管理
- **WinActor 管理**: WinActor の情報取得・更新・削除・再起動・利用状況エクスポート
- **ライセンス管理**: ライセンス情報取得・利用状況取得・FL利用状況エクスポート
- **ファイル操作**: ファイルのアップロード・ダウンロード
- **シナリオ管理**: シナリオ情報の取得・エクスポート
- **スケジュール管理**: スケジュールの作成・更新・削除・有効化・無効化
- **タスク管理**: タスク情報の取得・エクスポート
- **イベント管理**: イベント情報の取得
- **ユーザー管理**: ユーザー情報の取得・エクスポート
- **所属管理**: 所属情報の取得・エクスポート

## 動作環境

- Windows 10 以降
- WinActor 7.6 以上

## 利用上の注意

異なるメジャーバージョン間には互換性がありません。バージョンを混在させるとエラーが発生し、連携処理ができなくなります。
