# WinActor for WMC

WinActor for WMC は、RPA ツール「WinActor」から WinActor Manager on Cloud (WMC) の各種操作を行うためのライブラリです。

## 主な機能

| カテゴリ | 内容 | ノード数 |
|----------|------|:--------:|
| 認証 | アクセストークンの取得 | 1 |
| WinActor 管理 | 情報取得・更新・削除・再起動・利用状況エクスポート | 5 |
| ライセンス管理 | ライセンス情報取得・利用状況取得・FL 利用状況エクスポート | 3 |
| ファイル操作 | ファイルのアップロード・ダウンロード | 5 |
| シナリオ管理 | シナリオ情報の取得・エクスポート | 4 |
| スケジュール管理 | スケジュールの作成・更新・削除・有効化・無効化 | 18 |
| タスク管理 | タスク情報の取得・エクスポート | 3 |
| イベント管理 | イベント情報の取得 | 3 |
| ユーザー管理 | ユーザー情報の取得・エクスポート | 6 |
| 所属管理 | 所属情報の取得・エクスポート | 5 |

全 **53** ノードを提供しています。詳細は [ノードリファレンス](node-list.md) をご参照ください。

## 動作環境

| 項目 | 要件 |
|------|------|
| OS | Windows 10 以降 |
| WinActor | 7.6 以上 |

## はじめかた

1. [ライセンス認証ツール](setup/license-tool.md) でライセンス認証を行う
2. [準備](setup/index.md) に従って WinActor でアクセストークンを取得する
3. 各ノードをシナリオに追加して利用する

## 利用上の注意

!!! warning
    異なるメジャーバージョン間には互換性がありません。バージョンを混在させるとエラーが発生し、連携処理ができなくなります。
